# 05. 경제

화폐 단위: **데나리 (D)**. 모든 금액은 임시값이다.

## 시작 조건

| 항목 | 값 |
|---|---|
| 리그 | 선택한 국가의 2부 |
| 금고 | 4,000 D |
| 검투사 | 6명 (노예 위주, CA 30~60) |
| 직원 | 독토레 1명 (능력 낮음) |
| 시설 | 전부 Lv1 (비전 성소·유소년 학당·경비 초소는 Lv0 = 미건설) |

## 수입

| 항목 | 시점 | 설명 |
|---|---|---|
| **시즌 배당금** | 1주차 | 주 수입원. 아래 공식 |
| 경기 상금 | 경기 후 | 리그·생사 규칙별 표 참조. 승자 100%, 패자 30% |
| 관중 수입 | 홈 경기 후 | 홈 70% / 원정 30% |
| 판돈 | 경기 후 | 승자가 양측 판돈을 모두 가져감 |
| 후원 계약 | 매주 + 조건 달성 시 | 귀족·상인 후원 |
| 신전 후원 | 시즌 종료 | 케메르 1부 RP 상위 3팀 |
| 용병 보수 | 의뢰 완료 시 | [08 용병](08_mercenary.md) |
| 이적료·판매 | 거래 시 | |
| 판테온 컵 상금 | 단계별 | [04 리그와 대회](04_league.md) |

### 시즌 배당금

```
시즌 배당금 = 리그 기본액 × 순위 계수 × 국가 계수 배율

리그 기본액   : 1부 12,000 D / 2부 5,000 D
순위 계수     : 1.5 - (지난 시즌 리그 순위 / 10)   → 1위 1.4 ~ 10위 0.5
               (승격 팀은 0.6, 강등 팀은 1.2로 고정 = 낙하산 지원금)
국가 계수 배율 : 국가 순위 1~2위 ×1.2 / 3~4위 ×1.0 / 5~6위 ×0.85
```

배당금은 시즌 시작에 한 번에 들어온다. **24주를 버틸 계획**을 세우는 것이 운영의 핵심이다.

### 경기 상금 (승자 기준)

| 리그 | 훈련전 | 미시오 | 사투 |
|---|---|---|---|
| 2부 | 150 D | 450 D | 900 D |
| 1부 | 400 D | 1,200 D | 2,400 D |

단체전은 형식 배율(3:3 ×1.5, 5:5 ×2)을 곱한다. 국가 리그 특성(그롬마르 사투 +30% 등)도 적용한다.

### 관중 수입

```
관중 수입 = 홈 경기장 수용 인원 × 입장료 × 관중 배수
관중 배수 = 0.5 + (양측 출전 검투사 인기 평균 / 100) + (경기 열광도 / 200)
```

### 후원 계약

시즌 시작이나 이벤트로 제안이 온다. 한 번에 최대 2개까지 맺을 수 있다.

| 예시 | 주급 지원 | 조건 | 달성 보너스 | 위반 시 |
|---|---|---|---|---|
| 곡물상 조합 | +100 D/주 | 시즌 8승 이상 | 1,500 D | 지원 중단 |
| 원로 귀족 마르쿠스 | +200 D/주 | 승격 | 4,000 D | 다음 시즌 후원 불가 + 국가 호감도 -5 |
| 전쟁 상인 | +150 D/주 | 용병 파견 2회 이상 | 2,000 D | 지원 중단 |

## 지출 (매주)

| 항목 | 설명 |
|---|---|
| **검투사 주급** | 전원 지급. 아래 표 |
| 직원 급료 | 직원별 주급 |
| 식비 | 검투사 1인당 5 D (미노타우로스 10 D), 유소년 2 D |
| 시설 유지비 | 시설 레벨 합에 비례 |
| 장비 정비 | 경기 후 내구도 소모분 |
| 치료비 | 부상자 1인당 주 10~40 D (의무실 레벨이 높으면 감소) |
| 세금 | 그 주 수입의 10% (아우렐리아 20%) |
| 대출 이자 | 대출이 있을 때 |

### 주급 범위

| 등급 | 주급 |
|---|---|
| 유소년 | 2~5 D |
| 노예 (CA ~60) | 5~20 D |
| 자유민 (CA 60~100) | 20~80 D |
| 1부 주전 (CA 100~140) | 80~200 D |
| 스타 (CA 140+, 인기 70+) | 200~500 D |
| 직원 | 15~150 D |

주급은 CA, 인기, 나이, 종족, `탐욕` 수치로 결정된다. 자유민은 계약할 때 협상하고, 노예도 인기가 오르면 인상을 요구한다.

## 급료 미납

### 지급 순서

매주 1단계(주 시작)에 급료를 낸다. 금고가 모자라면 **라니스타가 지정한 우선순위**대로 지급하고, 못 받은 사람은 미납이 누적된다.

- 기본 우선순위: 직원 → 주급이 높은 검투사 순
- 개별 지정 가능: "스타 먼저", "노예 나중", "특정 검투사 제외" 등
- **밀린 급료 일괄 지급**: 미납 주수가 0으로 돌아가지만, 그동안 떨어진 사기는 절반만 회복된다.

### 미납 단계별 효과 (검투사 개인 기준)

| 누적 미납 | 사기 | 경기력 | 행동 |
|---|---|---|---|
| 1주 | -10 | — | 불만 메시지 |
| 2주 | -20 | -10% | 공개 불만 (다른 검투사 사기 -2) |
| 3주 | -30 | -25% | **태업**: 훈련 효율 0, 출전 요구 시 50% 확률로 거부 |
| 4주 이상 | -30/주 | -40% | **탈주** 판정 시작, **반란** 확률 가산 |

- `탐욕` 수치가 높으면 사기 하락폭이 커지고, `충성`이 높으면 줄어든다.
- 리자드폴크(`냉혈`)는 사기 하락이 절반이다.
- 직원도 미납되면 능력이 떨어지고(3주부터 효과 -50%), 4주 이상이면 사직한다.

### 탈주

```
탈주 확률(주간, 개인) = (미납 주수 - 3) × 8% × (1 - 충성 / 25) × (1 - 경비 초소 레벨 × 0.1)
```

탈주한 검투사는 사라진다. 노예였다면 국가에 신고해 현상금을 걸 수 있다 (50% 확률로 2~4주 뒤 돌아오지만 사기 0).

### 반란

매주 마지막 단계에서 루두스 단위로 판정한다.

```
반란 확률 = (100 - 검투사 평균 사기) × 최대 미납 주수 × 0.5%
          + 선동가 특성 보유자(사기 30 이하) 1명당 +5%p
          - 경비 초소 레벨 × 3%p
          - 사기 70 이상인 충견 특성 보유자 1명당 -3%p
```

**반란이 일어나면** 진압전이 벌어진다.

```
반란군   : 사기 30 이하 검투사 전원 (충견 특성 제외)
진압군   : 나머지 검투사 + 경비대 (경비 초소 레벨 × 2명분의 전투력)
진행     : 단체전 시뮬레이션으로 처리. 생사 규칙은 '미시오'와 같은 사망 판정
```

| 결과 | 효과 |
|---|---|
| 진압 성공 | 반란 주동자를 처형하거나 판매하거나 용서한다. 시설 1개 레벨 -1, 금고 10% 손실 |
| 진압 실패 | **루두스 몰수 → 게임 오버** |

반란 생존자는 `반란 생존자` 특성을 얻는다. 처형하면 남은 검투사 사기가 -15이고, 용서하면 주동자 충성 +3에 다른 검투사 사기 +5다. 대신 재반란 확률이 다음 4주간 2배가 된다.

| 대출처 | 한도 | 주 이자 | 연체 시 |
|---|---|---|---|
| 신전 금고 | 배당금의 30% | 1% | 국가 호감도 -10 |

## 파산

금고가 마이너스인 상태로 **4주 연속** 지나면 채권자에게 루두스가 압류되어 게임 오버다. 마이너스가 되면 즉시 경고가 뜨고, 3주차에는 "긴급 매각" 이벤트(검투사를 시장가의 50%에 즉시 판매)가 열린다.

## 영입 시장

### 노예 시장

- 시즌 시작과 겨울 이적 시장(12~13주)에 매물이 갱신된다. 카르세아 시장은 매주 일부 갱신된다.
- 국가별로 매물 종족 분포가 다르다 ([01 세계관](01_world.md)). 다른 나라 시장은 **중개인**이 있어야 이용할 수 있다.
- 가격: 200~1,500 D (CA·나이·종족에 따라).
- 패전국이 생기면 다음 시장 갱신에 **전쟁 포로 매물**이 대량으로 나온다 (싸지만 사기가 낮고 고향병 확률이 높음).

### 자유민 계약

- 계약이 끝난 자유 검투사, 은퇴를 미룬 노장, 해방민이 시장에 나온다.
- 이적료 없이 **계약금 + 주급**으로 영입한다. 협상 항목: 주급, 계약 기간(1~4시즌), 출전 보장, 사투 거부권.

### 이적

- 이적 시장 기간(1~2주, 12~13주)에만 가능하다.
- AI 루두스의 평가 가치:

```
가치 = CA^1.6 × 나이 계수 × (1 + 인기 / 100) × 계약 잔여 계수 × 성향 보정
```

- 제안 → 이적료 협상 → 검투사와 주급 협상 순으로 진행한다. 자유민은 이적을 거부할 수 있고, 노예는 거부할 수 없지만 사기가 -10 떨어진다.
- **중개인**이 있으면 이적료 -10~25% 협상, 다른 나라 루두스와 거래, 공개되지 않은 매물 발굴이 가능하다.

### 대여 (임대)

- 검투사를 다른 루두스나 경기 주최자에게 일정 주수 동안 빌려준다.
- 대여료는 주 단위이고, 대여 기간 주급은 빌려간 쪽이 낸다.
- 대여 중 **사망하면 계약서의 보상금**을 받는다 (기본 시장 가치의 120%). 돈은 들어오지만 검투사는 돌아오지 않는다.

### 판매

- 노예 검투사는 시장에 언제든 팔 수 있다 (시장 가치의 60%).
- 이적 시장 기간에는 다른 루두스에 제값을 받고 팔 수 있다.
