## 능력치 (1~20)

FM처럼 1~20 정수로 표시한다. 상대 검투사의 능력치는 스카우트 정확도에 따라 **범위**로 보인다 (예: `11~15`). [06 직원과 시설](06_staff_facilities.md) 참조.

### 신체 (6)

| 능력치 | 영향 |
|---|---|
| **근력** | 근접 피해, 방패 강타 성공률, 무거운 무기 사용 조건 |
| **민첩** | 행동 속도(턴 순서), 회피 보조, 그물·단검 효율 |
| **지구력** | 최대 스태미나, 긴 경기에서의 성능 유지 |
| **강인함** | 최대 HP, 부상 저항, 치명상 저항 |
| **반응** | 선공 판정, 받아치기·흘려내기 성공률 |
| **회복력** | 경기 간 피로 회복, 부상 회복 속도 |

### 기술 (5 + 무기 숙련)

| 능력치 | 영향 |
|---|---|
| **정확도** | 명중률, 치명타 확률, 투척·원거리 명중 |
| **회피** | 공격 회피 확률 |
| **막기** | 방패·무기로 공격을 막을 확률과 막았을 때 감쇠량 |
| **제압** | 넘어뜨리기, 붙잡기, 그물 탈출, 맨손 격투 |
| **마력** | 마법 스킬 위력과 사용 횟수. 0이면 마법 스킬을 배울 수 없음 |

**무기 숙련 (무기군별 1~20)**: 한손검, 대검, 도끼, 둔기, 창, 삼지창·그물, 단검, 투척, 방패, 맨손, 주술 촉매.
숙련도가 낮은 무기를 들면 명중과 피해에 페널티를 받는다 ([03 전투](03_combat.md)).

### 정신 (7)

| 능력치 | 영향 |
|---|---|
| **투지** | 불리할 때 버티는 힘. 낮으면 항복(손가락 들기)이 빨라짐 |
| **침착** | 큰 경기·위기 상황에서 실수 감소, 도발 저항 |
| **판단력** | 전투 AI의 스킬 선택 품질, 전술 지시 이행도 |
| **쇼맨십** | 관중 열광도 상승량, 인기 성장, 미시오 판정 생존률 |
| **공격성** | 공격 빈도. 높으면 공격적이지만 반격을 많이 맞음 |
| **규율** | 훈련 효율, 사기 하락 저항, 반란 가담 확률 감소 |
| **리더십** | 단체전에서 아군 기세 보너스, 루두스 내 사기 전파 |

## 현재 능력(CA)과 잠재력(PA)

- CA는 능력치의 가중합을 1~200으로 환산한 값이다. 가중치는 **전투 스타일별로 다르다** (그물투사는 민첩·제압 비중이 높고, 중장 검투사는 강인함·막기 비중이 높다).
- 훈련과 경기 경험으로 CA가 오르지만 PA를 넘을 수 없다.
- UI에는 CA/PA를 **별점(0.5~5성)** 으로 표시한다. PA 별점은 스카우트 정확도에 따라 범위로 보인다 (예: `★★★~★★★★☆`).

| CA | 별점 | 의미 |
|---|---|---|
| 0~39 | ★ 이하 | 견습, 2부 하위권 |
| 40~79 | ★★ | 2부 주전 |
| 80~119 | ★★★ | 1부 주전 |
| 120~159 | ★★★★ | 1부 에이스, 판테온 컵 수준 |
| 160~200 | ★★★★★ | 대륙의 전설 |

### 성장 공식 (주간)

```
CA 성장량 = 기본 성장 × 나이 계수 × 훈련 강도 × 코치 계수 × 시설 계수
           × 규율 계수 × 잠재력 여유 계수 × 종족 계수

잠재력 여유 계수 = clamp((PA - CA) / 40, 0.1, 1.0)   // PA에 가까울수록 성장 둔화
나이 계수        = 성장기 1.5 / 전성기 0.6 / 쇠퇴기 -0.5 (음수 = 하락)
```

- 성장량은 훈련 집중 분야의 능력치에 우선 배분된다 ([06 직원과 시설](06_staff_facilities.md)).
- **경기 경험치**: 실전 1경기는 훈련 2주 분량의 성장 효과가 있다. 사투에서 이기면 3주 분량.
- **쇠퇴기**에는 신체 능력치부터 떨어지고, 정신 능력치는 오히려 오를 수 있다 (노련함).

## 컨디션: 체력·경기감각·혹사도

FM처럼 몸 상태를 세 가지로 나눠 관리한다.

| 수치 | 범위 | 오르는 때 | 내리는 때 | 효과 |
|---|---|---|---|---|
| **체력** (피로의 반대) | 0~100 | 휴식, 회복력 | 경기 (훈련전은 덜), 강한 훈련 | 피로 70 이상이면 경기력 -15% |
| **경기감각** | 0~100 | 경기를 뛸 때 (+16, 훈련전 +10) | 5일 넘게 경기를 안 뛰면 매일 -1.2 | 40 미만이면 경기력 감소 (최대 -16%), 85 이상이면 +3% |
| **혹사도** | 0~100 | 경기마다 쌓이고, **7일 안에 다시 뛰면 크게** 쌓인다 | 매일 -1.2, 휴식 훈련이면 더 빨리 | 50 넘으면 경기력 감소 (최대 -20%), **85 이상이면 탈진** — AI는 내보내지 않고, 플레이어가 내보내면 손해가 크다 |

- 체력은 하루 이틀이면 돌아오지만 혹사도는 몇 주에 걸쳐 빠진다. 같은 스타를 계속 굴리면 체력이 괜찮아 보여도 혹사가 쌓인다.
- 경기 사이 최소 2일은 쉬어야 출전할 수 있다.

### 경기력 배율

사기·급료 미납·경기감각·혹사도·피로·경상을 모두 더해 **경기력 배율**(40%~110%) 하나로 만든다. 전투 시뮬레이션의 명중과 피해에 곱해진다. 연무장과 검투사 화면에서 항목별로 볼 수 있다.

## 일대기

- **시즌별 기록**: 시즌, 소속 루두스·리그, 출전·승·패·살해·부상, 시즌 시작과 끝의 능력(CA 변화), 인기, 벌어들인 돈. 통산 합계도 함께 보인다.
- **일대기**: 입단, 첫 승, 10승 단위, 살해, 부상, 깨달음, 판매·도주, 죽음 같은 사건이 날짜와 함께 쌓인다.
- 죽거나 떠난 검투사의 일대기도 남는다 (비석의 언덕).

## 인기 (0~100)

- 경기에서 관중 열광도를 많이 올릴수록, 이길수록 오른다. 출전하지 않으면 매주 -1씩 줄어든다.
- 효과: 경기 관중 수입 증가, 미시오 판정 생존률 증가, 이적 시장 가치 상승, 주급 인상 요구 증가.
- **인기 80 이상 + 통산 30승 이상**이면 관중이 **해방**을 요구한다 (아래 참조).

## 신분과 계약

| 신분 | 획득 경로 | 주급 | 계약 | 특징 |
|---|---|---|---|---|
| 노예 | 노예 시장, 전쟁 포로 | 낮음 | 무기한 | 충성 -3 보정. 언제든 판매 가능 |
| 자유민 | 자유민 계약, 이적 | 높음 | 1~4시즌 | 계약 만료 시 재계약 협상. 실패하면 자유 이적 |
| 해방민 | 해방된 노예 | 중간 | 1~3시즌 | 충성 +3 보정, 인기 보너스 |

### 해방(루디스) 이벤트

조건을 채우면 경기 직후 관중이 목검(*루디스*)을 외친다.

| 선택 | 결과 |
|---|---|
| **해방한다** | 루두스 명성 +, 국가 호감도 +5. 검투사는 해방민이 되어 재계약 협상 (충성이 높으면 잔류) |
| **거부한다** | 검투사 사기 -40, 충성 -5. 관중 인기 -20. 다음 경기부터 반란 선동 위험 |
| **나중에** (1회만) | 3주 유예. 그 안에 결정해야 함 |

해방된 검투사는 은퇴 후 **코치(독토레)** 로 영입할 수 있다 ([06 직원과 시설](06_staff_facilities.md)).

## 부상

부상은 **부위(머리·눈·팔·다리·몸통)**와 **단계(경상·중상·치명상)**가 있고, 종류는 `data/injuries.json`에 정의한다 (16종).

| 단계 | 기간 | 출전 | 예시 |
|---|---|---|---|
| 경상 | 3~12일 | 가능 (경기력 -15%, 30% 확률로 상처가 덧남) | 타박상, 발목 삠, 찢어진 눈썹 |
| 중상 | 10~42일 | 불가 | 갈비뼈 골절, 팔 골절, 뇌진탕, 어깨 탈구 |
| 치명상 | 30~90일 | 불가 | 두개골 골절, 무릎 인대 파열, 눈 부상, 손가락 절단 |

- **부상 중 능력치 저하**: 다리를 다치면 민첩·회피, 팔을 다치면 근력·정확도·막기, 머리를 다치면 판단력·침착이 떨어진다.
- **어디를 다치는가**: 경기에서 가장 크게 맞은 부위가 부상 부위가 된다. 교범의 노리는 곳(머리·다리·팔)이 상대 부상 부위에 영향을 준다.
- **영구 손상**: 다 나을 때 확률로 후유증이 남는다. 능력치가 영구히 떨어지거나 특성(외눈, 절름발이, 흉터투성이)이 생긴다. 의무실 단계와 메디쿠스 실력이 확률을 낮추고, 드워프는 강철 뼈 덕에 덜 남는다.
- **악화**: 다친 채로 출전하면 30% 확률로 회복 기간이 1.6배로 늘어난다.
- **회복**: 매일 진행된다. 의무실, 메디쿠스, 리자드폴크(2배), 휴식 훈련(1.5배)이 빠르게 한다.
- 막사의 **의무실** 칸에서 부상자와 회복 진행률을 보고, 부상 표시에 마우스를 올리면 능력치 저하와 영구 손상 위험이 보인다.

## 특성 (Trait)

검투사 한 명당 특성은 **최대 5개**. 생성 시 1~2개를 갖고, 경기·사건·나이로 새로 얻거나 잃는다.
`(숨김)` 표시는 스카우트나 코치가 판독해야 보인다.

### 성격 특성

| 특성 | 효과 | 획득 |
|---|---|---|
| 강철 심장 | 침착 +3, 큰 무대 보정 2배 | 생성 / 판테온 컵 결승 승리 |
| 겁쟁이 | 투지 -4, HP 40% 이하에서 항복 확률 대폭 증가 | 생성 / 사투 생존 후 일정 확률 |
| 광전사 | 공격성 +5, 막기 -3, 피의 격노 효과 2배(오크만) | 생성 / 연속 KO 승 |
| 냉정한 계산가 | 판단력 +3, 쇼맨십 -2 | 생성 |
| 탐욕스러운 자 | 주급 인상 요구 2배, 미납 시 사기 하락 1.5배 | 생성 (숨김) |
| 충견 | 충성 최대, 반란 가담 불가 | 생성 / 해방 후 잔류 |
| 선동가 | 사기 30 이하일 때 주변 검투사의 반란 확률 증가 | 생성 (숨김) / 해방 거부당함 |
| 야심가 | 성장 +15%, 2시즌마다 이적·해방 요구 | 생성 |
| 늦게 피는 꽃 | 전성기가 3년 늦게 시작하고 3년 늦게 끝남 | 생성 (숨김) |
| 조숙 | 성장기 성장 +30%, 전성기가 2년 짧음 | 생성 (숨김) |
| 편견 없음 | 종족 간 감정 무시 | 생성 |
| 향수병 | 출신국 밖 루두스에서 주간 사기 -2 | 생성 |

## 은퇴

- 쇠퇴기에 CA가 일정 이하로 떨어지거나 은퇴 권장 나이를 넘기면 은퇴를 요청한다.
- 은퇴한 검투사는 성향에 따라 **코치, 유소년 학당장, 스카우트** 후보로 직원 시장에 나온다. 해당 루두스 출신은 영입 우선권이 있다.
- 사망하거나 은퇴한 검투사는 **명예의 전당**(통산 전적, 최고 인기, 별명, 사인)에 기록된다.
