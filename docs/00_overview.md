# 00. 개요

## 한 줄 컨셉

> 판타지 대륙의 작은 검투사 양성소 주인이 되어, 검투사를 사고·키우고·잃어가며
> 국가 리그 정상과 대륙 최강 대회 **판테온 컵**을 노린다.

## 플레이어 역할

**라니스타**(검투사 양성소 *루두스*의 주인). 직접 싸우지 않는다. 사람을 고르고, 돈을 굴리고, 누구와 언제 싸울지를 결정한다.

## 디자인 원칙 (기둥)

1. **잃을 수 있어야 의미가 있다**
   검투사의 죽음은 되돌릴 수 없다. 부활, 롤백, 보험은 없다. 모든 경기 신청이 리스크 판단이 된다.
2. **싸움은 고르는 것이다**
   고정 대진표가 없다. 도전을 걸고, 받고, 피한다. 피하면 대가가 있다.
3. **돈이 사람을 붙잡는다**
   모든 검투사는 급료를 받는다. 돈이 마르면 사기가 무너지고, 결국 칼끝이 주인을 향한다.
4. **사람은 늙고 떠난다**
   전성기, 해방, 은퇴, 죽음이 로스터를 끊임없이 순환시킨다. 세대교체가 곧 게임이다.
5. **세계는 나와 무관하게 움직인다**
   국가 간 전쟁, 다른 루두스의 성장과 몰락, 국가 랭킹 변동이 플레이어에게 기회와 위기를 던진다.

## 목표 구조

| 단계 | 목표 | 보상 |
|---|---|---|
| 단기 (주) | 도전 경기 승리, 급료 지급 유지 | 상금, RP, 인기 |
| 중기 (시즌) | 리그 승격 / 잔류 | 시즌 배당금 증가, 명성 |
| 장기 (수 시즌) | 국가 1부 상위권 → 판테온 컵 출전 | 막대한 상금, 국가 계수 기여 |
| 최종 | 판테온 컵 우승, 왕조 구축 | 명예의 전당 |

## 핵심 루프

```
[시즌 시작]  배당금 수령 → 시장 갱신 → 영입·이적·급료 협상 → 유소년 입학
     │
     ▼
[매주 반복]  급료 지급 → 도전 응답/신청 → 훈련 배분 → 경기 진행
            → 부상·사망·사기 처리 → 반란 판정 → 이벤트(전쟁·용병 의뢰)
     │
     ▼
[시즌 종료]  RP 순위 확정 → 승강전 → 국가 계수 갱신 → 계약 만료·해방·은퇴
```

## 시즌 캘린더 (1시즌 = 24주)

| 주차 | 내용 |
|---|---|
| 1~2 | 프리시즌. **이적 시장 개방**, 시즌 배당금 지급, 유소년 입학 |
| 3 | 정규 기간 시작 (도전 경기 가능) |
| 5, 7, 9, 11, 13, 15 | 판테온 컵 조별리그 (출전 팀만) |
| 12~13 | **겨울 이적 시장** |
| 17 | 판테온 컵 8강 |
| 19 | 판테온 컵 4강 |
| 22 | 판테온 컵 결승 (아우렐리온 대콜로세움) |
| 23 | 승강전 |
| 24 | 시즌 정산: 순위 확정, 승강, 계약 만료, 은퇴, 해방, 나이 증가 |

- 정규 기간(3~22주)에는 언제든 도전을 신청하고 받을 수 있다.
- 검투사 한 명은 **주당 최대 1경기**만 뛸 수 있다. 연속 출전하면 피로가 누적된다.
- 국가 간 전쟁 이벤트는 시즌 중 무작위로 발생한다 ([08 용병](08_mercenary.md)).

## 실패 조건

- **파산**: 금고가 마이너스인 상태로 4주가 지나면 채권자에게 루두스가 압류된다.
- **반란 진압 실패**: 루두스를 빼앗긴다.
- **리그 자격 상실**: 2부 최하위로 시즌을 마쳤는데 파산 상태면 리그에서 퇴출된다.

게임 오버 후에도 **명예의 전당 기록**은 남고, 새 루두스로 다시 시작할 수 있다.

## 톤

- 로마 검투사 문화를 뼈대로 한 **로-판타지**. 종족, 마법, 야수가 있지만 세계의 중심은 돈과 피와 관중이다.
- 무겁지만 절망적이지는 않다. 관중의 환호, 라이벌전, 해방된 스타의 은퇴식 같은 **영광의 순간**을 충분히 준다.
