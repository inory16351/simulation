# 12. UI (경기 밖 화면)

경기 밖은 **FM처럼 정보 중심 UI**로 만든다. 연출보다 **빠른 판단**이 목표다. 분위기는 초상화·문장·아이콘 같은 이미지와 어두운 테두리로 낸다.

## 기본 레이아웃

```
┌────────────────────────────────────────────────────────────────────────┐
│ [문장] 루두스 이름 · 리그 · RP 순위      시즌 1 · 7주차   금고 3,240 D │ [계속 ▶] │
├──────────────┬─────────────────────────────────────────────────────────┤
│ 받은편지함 (3)│  화면 제목                          [탭] [탭] [탭]     │
│ 개요          │ ─────────────────────────────────────────────────────── │
│ 로스터        │                                                         │
│ 훈련          │   메인 영역 (표 / 카드 / 상세)                          │
│ 도전          │                                                         │
│ 일정·리그     │                                                         │
│ 시장          │                                                         │
│ 직원          │                                                         │
│ 시설          │                                                         │
│ 재정          │                                                         │
│ 세계          │                                                         │
│ 명예의 전당   │                                                         │
└──────────────┴─────────────────────────────────────────────────────────┘
```

- **상단 바**: 루두스 문장과 이름, 리그와 순위, 날짜, 금고. 오른쪽 끝에 **[계속]** 버튼(FM의 Continue). 처리하지 않은 필수 결정(선택지 이벤트, 들어온 도전 응답)이 있으면 계속 버튼이 막히고 그쪽으로 안내한다.
- **좌측 사이드바**: 메뉴. 처리할 게 있는 메뉴에는 숫자 배지.
- **메인 영역**: 표 중심. 행을 클릭하면 상세 화면으로 이동.
- **경고**: 급료 부족 예상, 반란 위험, 파산 경고는 상단 바 아래 붉은 띠로 표시.

## 화면 목록

| 화면 | 내용 |
|---|---|
| **받은편지함** | 이벤트, 경기 결과, 도전 도착, 스카우트 보고서, 시장 소식. FM처럼 게임의 중심 |
| **개요** | 루두스 요약: 다음 경기, 리그 순위 미니표, 재정 추이, 사기·부상 현황 |
| **로스터** | 검투사 표: 초상화 썸네일, 이름, 종족, 나이, 스타일, CA/PA 별점, 사기, 피로, 부상, 주급, 미납 |
| **검투사 상세** | 아래 별도 레이아웃 |
| **훈련** | 검투사별 집중 분야·강도 배정 표, 교관 배정, 스킬 수련 진행도 |
| **도전** | 받은 도전(수락/역제안/거절), 도전 신청(상대 선택 → 조건 설정), 확정된 경기 |
| **일정·리그** | 리그 순위표(RP), 지난 경기 결과, 승강 구간 표시 |
| **시장** | 노예 시장 / 자유민 / 이적 대상 탭. 필터와 정렬 |
| **직원** | 직원 표와 고용 시장 |
| **시설** | 시설 카드(레벨, 효과, 증축 비용·기간) |
| **재정** | 주간 수입·지출 내역, 급료 우선순위, 대출 |
| **세계** | 국가 관계, 국가 계수 순위, 전쟁 현황, 용병 의뢰 게시판 |
| **명예의 전당** | 전설과 묘비 |

## 검투사 상세 레이아웃

```
┌───────────────┬──────────────────────────────────────────────────────┐
│  [초상화]      │ 이름 "별명"         종족 · 출신국 · 나이(전성기)     │
│               │ 스타일 · 신분 · 주급 · 계약                          │
│  CA ★★★       │ 사기 ███████░░  인기 ████░░░  피로 ██░░░░             │
│  PA ★★★~★★★★  │ 특성: [관중의 총아] [강철 턱] [?]                    │
├───────────────┴───────────────┬──────────────────────────────────────┤
│ 신체          │ 기술           │ 정신              │ 무기 숙련        │
│ 근력      14  │ 정확도     12  │ 투지      15      │ 한손검  ██████ 14 │
│ 민첩      11  │ 회피        9  │ 침착      10      │ 방패    ████   10 │
│ ...           │ ...            │ ...               │ ...              │
├───────────────────────────────┴──────────────────────────────────────┤
│ 스킬 슬롯 [강타][철벽][받아치기][ ]   패시브 [불굴][ ]               │
│ 장비 [글라디우스][대방패][사슬 갑옷][볏 투구]                         │
│ 전적 12승 4패 · 최근 경기 · 부상 이력                                 │
└──────────────────────────────────────────────────────────────────────┘
```

- 능력치 숫자는 FM처럼 구간별 색으로 표시한다 (1~5 회색, 6~10 양피지, 11~15 청동, 16~20 횃불색).
- 판독이 덜 된 값은 `11~15`처럼 범위로, 숨김 특성은 `[?]`로 보인다.

## 시각 규칙

- 배경은 숯 어둠, 패널은 한 단계 밝은 어둠. 테두리는 바랜 청동 1px.
- 표 행 높이는 촘촘하게. 숫자는 오른쪽 정렬과 고정폭 숫자를 쓴다.
- 이미지가 들어가는 자리: 초상화(로스터 썸네일, 상세), 루두스 문장, 국가 문장, 무기·스킬·특성 아이콘, 시설 카드 일러스트.
- 이미지가 준비되기 전에는 **플레이스홀더**(종족색 실루엣 + 이니셜)를 쓴다.
