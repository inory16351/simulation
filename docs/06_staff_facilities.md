# 06. 직원과 시설

## 직원

### 직원 능력치 (1~20)

| 능력치 | 영향 |
|---|---|
| 신체 지도 | 근력·민첩·지구력·강인함·반응·회복력 훈련 효율 |
| 기술 지도 | 정확도·회피·막기·제압·무기 숙련 훈련 효율 |
| 정신 지도 | 정신 능력치 훈련 효율 |
| 마법 지도 | 마력 훈련, 마법 스킬 습득 속도 |
| 동기부여 | 담당 검투사 주간 사기 +, 규율 낮은 검투사 통제 |
| **능력 판독** | 검투사 능력치를 얼마나 정확하게 보는가 |
| **잠재력 판독** | 숨김 PA와 숨김 능력치·특성을 얼마나 정확하게 보는가 |
| 의술 | 부상 회복 속도, 응급 처치 성공률 |
| 협상 | 이적료·주급·후원·용병 보수 협상 |
| 인맥 (국가별) | 해당 국가 시장·정보 접근, 스카우트 정확도 보너스 |
| 무력 | 경비대 진압력 |

직원도 종족, 나이, 주급, 계약 기간이 있다. 은퇴한 검투사는 전성기 능력치와 스타일을 반영한 지도 능력치를 갖고 직원 시장에 나온다.

### 직책

| 직책 | 인원 | 핵심 능력치 | 역할 |
|---|---|---|---|
| **독토레** (수석 코치) | 1 | 지도 전반, 동기부여, 능력 판독 | 전체 훈련 효율 +, 소속 검투사 능력치 판독, 경기 전술 조언 |
| **교관** | 시설에 따라 1~4 | 분야별 지도 | 훈련 그룹 담당. 최대 6명 지도 |
| **학당장** | 1 (학당 건설 시) | 지도 전반, 잠재력 판독 | 유소년 훈련과 입학생 평가 ([07 유소년](07_youth.md)) |
| **스카우트** | 0~3 | 능력 판독, 잠재력 판독, 인맥 | 지정 국가·시장의 검투사 조사 |
| **중개인** (에이전트) | 0~1 | 협상, 인맥 | 이적·용병 의뢰 중개, 타국 시장 접근 |
| **메디쿠스** (의사) | 0~2 | 의술 | 부상 회복, 경기 중 응급 처치 |
| **재무관** | 0~1 | 협상 | 세금 감면, 대출 이자 감면, 미납 시 사기 하락 완화 |
| **경비대장** | 0~1 | 무력, 동기부여 | 탈주 방지, 반란 진압 지휘 |

총 직원 수는 **본관** 레벨로 제한된다 (아래 시설 표).

### 스카우팅과 정보의 안개

남의 검투사는 능력치·CA·PA가 **범위**로 보인다. 정찰을 맡기면 범위가 좁아진다. 자세한 규칙은 [05 경제 — 선수 찾기와 정찰](05_economy.md#선수-찾기와-정찰).

- **정찰꾼**: 실력이 좋을수록 동시에 여러 명(2 + 실력/8)을 더 빨리(하루 4 + 실력×0.7) 조사하고, PA 범위도 좁게 본다. 우리 검투사의 PA도 정찰꾼 실력만큼만 보인다.
- **중개인**: 이적료를 깎고, 우리 검투사를 팔 때 더 받는다. 용병 의뢰 보수에도 붙는다 ([08 용병](08_mercenary.md)).
- 식솔을 고용할 때도 루두스 명성이 낮으면 거절하거나 주급을 더 달라고 한다 ([05 경제 — 루두스 명성과 영입 의사](05_economy.md#루두스-명성과-영입-의사)).

> 설계 초안의 판독 능력치 세분화(능력 판독/잠재력 판독/국가 인맥), 주간 보고서 문구, 공개되지 않은 매물 발굴은 확장 후보로 남긴다.

## 훈련 시스템

### 주간 훈련 배정

검투사마다 매주 **집중 분야**와 **강도**를 정한다. 교관 한 명이 최대 6명을 지도하고, 교관의 전문 분야와 집중 분야가 맞으면 효율이 오른다.

| 집중 분야 | 성장 대상 |
|---|---|
| 신체 | 신체 능력치 6종 |
| 무기술 | 지정한 무기군 숙련 + 정확도 |
| 방어 | 막기, 회피, 방패 숙련 |
| 격투 | 제압, 맨손 숙련 |
| 정신 | 투지, 침착, 판단력, 규율 (코치의 정신 지도 의존도가 높음) |
| 마법 | 마력, 마법 스킬 (비전 성소 필요) |
| 쇼맨십 | 쇼맨십, 인기 소폭 |
| 스킬 수련 | 지정한 스킬 습득 진행도 |
| 스타일 전환 | 보조 스타일 습득 진행도 |
| 휴식 | 성장 없음, 피로 대폭 회복, 부상 회복 가속 |

| 강도 | 성장 배율 | 피로 증가 | 훈련 부상 확률 |
|---|---|---|---|
| 휴식 | 0 | -30 | 0% |
| 낮음 | ×0.6 | +5 | 0.5% |
| 보통 | ×1.0 | +10 | 1% |
| 높음 | ×1.4 | +20 | 3% |
| 극한 | ×1.8 | +35 | 6% (사기 -3) |

- 피로 70 이상이면 경기력 -15%, 90 이상이면 출전 불가.
- 경기에 나간 주에는 훈련 효과가 절반이다 (경기 경험치는 별도로 들어온다).

### 성장 배분

[02 검투사](02_gladiator.md)의 CA 성장 공식으로 계산한 성장량을 집중 분야 능력치에 우선 배분한다. 집중하지 않은 능력치도 10% 정도 자연 성장한다. 쇠퇴기에는 집중 분야의 하락을 늦추는 용도로 쓴다.

### 스킬 습득

```
필요 수련치  : 스킬 등급에 따라 100 / 200 / 400
주간 수련치  = (관련 능력치 평균 × 2 + 담당 교관 지도 × 3) × 강도 배율 × 시설 계수
```

- 습득 조건(능력치, 무기 숙련, 종족)을 만족해야 수련을 시작할 수 있다.
- **마법 스킬**: 비전 성소 Lv1 이상 + 마법 지도 10 이상 교관 필요.
- **종족 고유 스킬**: 같은 종족 교관이 있으면 수련치 ×1.5, 없으면 ×0.5.
- **전수**: 은퇴한 검투사 출신 교관은 자신이 쓰던 스킬을 수련치 ×2로 가르친다.
- 비급서(이벤트·용병 보상 아이템)를 쓰면 조건만 맞을 때 즉시 습득한다.
