# 11. 랜덤 이벤트

FM과 달리 이 게임은 **운이 판을 흔든다**. 매주 무작위 이벤트가 일어나 이득과 손해를 동시에 던진다. 좋은 운은 기회지만 대가가 따르고, 나쁜 운도 선택에 따라 줄일 수 있다.

## 원칙

1. **대부분의 이벤트에는 선택지가 있다.** 운이 결과를 정하는 게 아니라 상황을 던지고, 플레이어가 대응한다.
2. **좋은 이벤트에도 대가가 있다.** 공짜 이득은 드물게만 준다.
3. **치명적인 연쇄는 막는다.** 큰 악재가 일어나면 4주 동안 큰 악재가 다시 나오지 않는다.
4. **운은 기록된다.** 시즌 결산에 그 시즌의 행운·불운 지수를 보여준다.

## 발생 규칙

```
매일 아침에 판정 (7일 기준 기대 횟수는 이전 주간 확률과 같게 맞춘다):
  루두스 이벤트   : 하루 12% 확률로 1건 (가중치 추첨)
  검투사 이벤트   : 소속 검투사마다 하루 0.6% 확률
  세계 이벤트     : 하루 2.3% 확률로 1건 (모든 루두스에 영향)
  같은 날 루두스 이벤트는 최대 1건
큰 악재 쿨다운   : 등급 '재앙' 발생 후 28일간 '재앙' 제외
조건 필터        : 각 이벤트의 발생 조건(시설, 금고, 사기, 국가 등)을 만족해야 추첨 대상
```

이벤트 등급: `행운`(좋음) / `기회`(선택에 따라 좋음) / `시련`(나쁨, 대응 가능) / `재앙`(매우 나쁨, 드묾)

결과는 **받은편지함**에 메시지로 오고, 선택지가 있으면 그 주를 넘기기 전에 골라야 한다.

## 루두스 이벤트

| 이벤트 | 등급 | 조건 | 내용 | 선택지 → 결과 |
|---|---|---|---|---|
| 익명의 후원자 | 행운 | — | 누군가 금고에 돈을 넣고 갔다 | 받는다 → +800~2,000 D. 30% 확률로 2주 뒤 "후원자의 요구"(특정 경기 승부 조작 요청) 연쇄 |
| 상인의 할인 | 기회 | — | 무기 상인이 재고를 처분한다 | 산다 → 정교 장비 1개 50% 가격 / 무시 |
| 떠돌이 고수 | 기회 | — | 은퇴한 전설이 루두스 앞에 나타났다 | 교관으로 고용(주급 높음, 지도 18) / 한 번 시범 수련(검투사 1명 스킬 즉시 습득, 300 D) / 돌려보냄 |
| 유랑 극단의 제안 | 기회 | — | 쇼 공연에 검투사를 빌려달라 | 빌려준다 → +600 D, 인기 +5, 해당 검투사 1주 훈련 불가 / 거절 |
| 귀족의 연회 초대 | 기회 | 명성 일정 이상 | 스타 검투사를 연회에 데려오라 | 간다 → 후원 계약 제안 확률↑, 검투사 피로 +15 / 거절 → 귀족 호감 하락 |
| 도박꾼의 제보 | 기회 | — | 다음 상대의 약점 정보를 판다 | 산다(200 D) → 다음 경기 상대 능력치 정확히 공개 + 명중 +5% / 무시 |
| 승부 조작 제안 | 기회 | — | 다음 경기를 져주면 큰돈을 주겠다 | 수락 → +3,000 D, RP 손해, 30% 확률로 발각(명성 폭락, 국가 호감 -30) / 거절 → 제안자가 원한형 AI로 변함 |
| 역병 | 시련 | — | 숙소에 열병이 돈다 | 의사 고용(비용) → 피해 최소화 / 격리 → 검투사 2~4명 2주 출전 불가 / 방치 → 무작위 3명 능력치 소폭 하락, 낮은 확률로 사망 |
| 화재 | 시련 | — | 무기고에 불이 났다 | 진화 비용 지불 → 장비 일부 손실 / 방치 → 시설 1개 레벨 -1 |
| 도둑 | 시련 | 경비 초소 Lv2 이하 | 금고가 털렸다 | 금고의 5~15% 손실. 경비 초소 레벨이 높으면 범인을 잡아 일부 회수 |
| 세무 감사 | 시련 | 아우렐리아 또는 수입 많음 | 장부를 조사한다 | 뇌물(500 D) → 무사 / 정직하게 → 추징금 무작위(0~2,000 D) |
| 우물 오염 | 시련 | — | 물이 썩었다 | 수리(400 D) / 방치 → 2주간 전원 피로 회복 절반 |
| 지진 | 재앙 | 라케다이몬, 케메르 | 건물이 무너졌다 | 시설 2개 레벨 -1, 부상자 발생 |
| 반란의 불씨 | 재앙 | 평균 사기 40 이하 | 선동가가 비밀 회합을 연다 | 주동자 처벌 → 사기 -5, 반란 확률 리셋 / 급료 인상 약속 → 다음 4주 주급 +20% / 무시 → 반란 확률 2배 |

## 검투사 이벤트

| 이벤트 | 등급 | 조건 | 내용 | 결과 |
|---|---|---|---|---|
| 깨달음 | 행운 | 훈련 중 | 수련 중 무언가를 깨달았다 | 능력치 1개 +1~2, 낮은 확률로 스킬 즉시 습득 |
| 잠재력 각성 | 행운 | 성장기, 매우 드묾 | 숨은 재능이 터졌다 | PA +10~30 |
| 관중의 연인 | 행운 | 인기 50 이상 | 귀족 부인이 팬이 되었다 | 인기 +10, 선물 +300 D. 20% 확률로 "질투한 남편" 연쇄(암살 시도) |
| 고향의 편지 | 기회 | 출신국이 다른 나라 | 가족 소식이 왔다 | 송금해 준다(200 D) → 사기 +15, 충성 +1 / 무시 → 사기 -5 |
| 결투 신청 | 기회 | — | 다른 루두스 검투사가 공개적으로 도발했다 | 받는다 → 다음 주 미시오 경기 자동 확정, 이기면 인기 +15 / 거부 → 인기 -10 |
| 술집 난투 | 시련 | 규율 10 이하 | 밤에 몰래 나가 싸움을 벌였다 | 벌금 100~300 D, 경상 확률. 처벌하면 사기 -10 / 눈감으면 규율 -1 |
| 상처 감염 | 시련 | 부상 중 | 상처가 곪았다 | 의무실 레벨에 따라 회복 기간 +1~3주, 낮은 확률로 영구 손상 |
| 연애 | 기회 | 같은 루두스 | 두 검투사가 가까워졌다 | 둘 다 사기 +10. 한 명이 죽거나 떠나면 남은 쪽 사기 -40 |
| 마음의 병 | 시련 | 동료 사망 직후 | 잠을 못 이룬다 | 휴식 2주 → 회복 / 계속 출전 → `겁쟁이` 특성 획득 확률 |
| 탈주 계획 발각 | 시련 | 노예, 사기 30 이하 | 탈주를 모의하다 걸렸다 | 처벌 → 사기 -10, 탈주 확률 리셋 / 해방 약속 → 충성 +5, 약속 기한 생김 |
| 독살 시도 | 재앙 | 인기 60 이상 또는 라이벌 존재 | 누군가 음식에 독을 탔다 | 메디쿠스 의술로 판정 → 무사 / 중상 / 매우 낮은 확률로 사망 |

| 이벤트 | 등급 | 내용 | 영향 |
|---|---|---|---|
| 황제의 축제 | 행운 | 제국 전역에서 축제가 열린다 | 4주간 관중 수입 +50% (아우렐리아는 +100%) |
| 풍년 | 행운 | 곡물 값이 떨어졌다 | 4주간 식비 절반 |

| 노예선 난파 | 기회 | 카르세아 노예선이 해안에 좌초했다 | 2주간 노예 시장 가격 -40%, 매물 증가 |
| 기근 | 시련 | 흉작 | 8주간 식비 2배 |
| 전염병 유행 | 시련 | 대륙에 역병이 돈다 | 4주간 관중 수입 -50%, 모든 루두스에 역병 이벤트 확률 증가 |
| 국경 분쟁 | 시련 | 두 나라 관계 -20 | 전쟁 발생 확률 상승 ([08 용병](08_mercenary.md)) |
| 황제 암살 | 재앙 | 아우렐리아 정변 | 아우렐리아 리그 배당금 다음 시즌 -20%, 국가 관계 무작위 변동 |

## 운 보정 (숨은 장치)

- 플레이어가 **연속으로 재앙·시련**을 겪으면 다음 이벤트 추첨에서 `행운` 가중치가 조금씩 오른다 (최대 2배). 완전히 무너지는 것을 막는 안전망이다.
- 반대로 `행운`이 연속되면 `시련` 가중치가 오른다.
- 이 보정은 UI에 표시하지 않는다.

## 데이터 형식 (예)

```json
{
  "id": "event.wandering_master",
  "scope": "ludus",
  "grade": "opportunity",
  "weight": 3,
  "conditions": [],
  "title": "떠돌이 고수",
  "text": "낡은 망토를 두른 노인이 루두스 문 앞에 섰다. 손에 굳은살이...",
  "choices": [
    { "label": "교관으로 고용한다", "effects": [{ "type": "addStaff", "template": "legend_trainer" }] },
    { "label": "한 번만 가르쳐 달라 (300 D)", "effects": [{ "type": "gold", "value": -300 }, { "type": "learnSkillRandom", "target": "chosen" }] },
    { "label": "돌려보낸다", "effects": [] }
  ]
}
```

이벤트는 전부 `data/events.json`에 데이터로 정의하고, 효과 타입(`gold`, `morale`, `attr`, `trait`, `injury`, `facility`, `chain` 등)만 코드로 구현한다.
