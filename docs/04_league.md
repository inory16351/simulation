# 04. 리그와 대회

## 전체 구조

```
                    ┌─────────────────────────┐
                    │   판테온 컵 (대륙 최강전)  │  ← 국가 계수 순위로 출전권 배분
                    └────────────▲────────────┘
        ┌──────────┬──────────┬──┴───────┬──────────┬──────────┐
   아우렐리아   그롬마르    실바렌     돌가르    카르세아    케메르
     1부(10)    1부(10)    1부(10)   1부(10)   1부(10)    1부(10)
     2부(10)    2부(10)    2부(10)   2부(10)   2부(10)    2부(10)
```

- 국가마다 **1부 10팀 + 2부 10팀**, 대륙 전체 120개 루두스.
- 플레이어는 원하는 국가의 **2부 하위권**에서 시작한다.
- MVP에서는 국가 1개(2개 리그 20팀)만 구현하고 나머지 국가는 계수 계산용으로 추상 시뮬레이션한다 ([10 기술 구조](10_tech.md)).

## 랭킹 점수 (RP)

루두스 하나가 RP 하나를 가진다. **승강, 시즌 배당금, 판테온 컵 출전권**이 모두 RP 순위로 결정된다.

### 초기값과 시즌 보정

| 상황 | RP |
|---|---|
| 1부 신규·승격 팀 | 1500 |
| 2부 신규·강등 팀 | 1200 |
| 시즌 시작 시 | 리그 기준값 쪽으로 25% 회귀 (`RP = RP - (RP - 기준) × 0.25`) |

시즌 시작 회귀는 압도적인 팀이 영원히 1위를 독점하는 것을 막고, 매 시즌 경쟁을 다시 연다.

### RP 변동 (Elo 방식)

```
기대승률 E  = 1 / (1 + 10^((상대 RP - 내 RP) / 400))
RP 변동     = K × (결과 - E)          결과: 승 1, 패 0
K           = 32 × 형식 배율 × 생사 규칙 배율 × 리그 간 보정

형식 배율       : 1:1 ×1.0 / 3:3 ×1.5 / 5:5 ×2.0
생사 규칙 배율  : 훈련전 ×1.0 / 미시오 ×1.5 / 사투 ×2.0
리그 간 보정    : 2부 팀이 1부 팀을 이기면 ×1.25
```

- 강팀을 이기면 많이 오르고, 약팀을 이기면 거의 오르지 않는다. 약팀 사냥으로는 순위를 올리기 어렵다.
- **같은 상대와의 반복 경기**: 시즌 중 같은 루두스와 3번째 경기부터 RP 변동이 절반이 된다.

## 도전 시스템

정해진 대진표가 없다. 정규 기간(3~22주)에는 매주 도전을 **신청**하고 **받는다**.

### 신청 가능 범위

| 대상 | 조건 |
|---|---|
| 같은 리그 | 전부 가능 |
| 인접 리그 (1부 ↔ 2부) | RP 차이 ±200 이내 |
| 다른 국가 루두스 | **원정 친선전**만 가능 (RP 변동 없음, 상금과 국가 호감도만 변동) |

- 주당 신청 가능 횟수 = **2회** (+ 루두스 명성 단계에 따라 최대 4회).
- 출전 가능한 검투사가 없으면 신청할 수 없다.

### 도전 조건

| 항목 | 선택지 |
|---|---|
| 형식 | 1:1 / 3:3 / 5:5 |
| 생사 규칙 | 훈련전 / 미시오 / 사투 (실바렌 국내 리그는 사투 불가) |
| 지명 | 상대 검투사 1명 지명 가능. 상대는 수락하거나 대체 선수를 제시 |
| 판돈 | 0 ~ 상한(리그별, 카르세아는 2배). 승자가 모두 가져감 |
| 장소 | 받는 쪽 홈 경기장. 관중 수입은 홈 팀이 70%를 가져감 |

### 들어온 도전에 대한 응답

| 응답 | 효과 |
|---|---|
| **수락** | 다음 주 경기 확정 |
| **역제안** | 조건 1개를 수정해서 돌려보냄. 상대 AI가 수락하거나 철회 |
| **거절** | 시즌당 무료 거절 **3회**. 이후 거절마다 RP -10, 루두스 명성 하락 |

- **하위 RP 팀의 도전을 거절**하면 페널티가 2배이고 "겁쟁이 루두스" 평판이 쌓인다. 평판이 쌓이면 관중 수입이 줄고 후원이 끊긴다.
- 사투 도전은 거절해도 페널티가 절반이다 (목숨을 걸지 않는 건 이해받는다).

### 최소 활동량

- 시즌 중 **최소 8경기**를 치러야 한다. 모자란 경기 1개당 시즌 종료 시 RP -25.
- 1위를 찍고 숨어 버티는 플레이를 막는다.

### AI 루두스 성향

| 성향 | 도전 패턴 |
|---|---|
| 공격형 | 사투·미시오를 자주 신청. 높은 RP 팀에 도전 |
| 안정형 | 훈련전 위주. 자기보다 약한 팀만 고름. 들어온 사투는 거절 |
| 원한형 | 자기 검투사를 죽인 루두스에 집요하게 도전. 사투 비율 높음 |
| 상인형 | 판돈 경기 선호. 승률이 높을 때만 신청 |
| 육성형 | 유망주를 훈련전에 내보냄. 이적 시장에서 판매에 적극적 |

국가 문화가 성향 분포에 영향을 준다 (그롬마르는 공격형, 카르세아는 상인형이 많음).

## 시즌 종료와 승강

시즌 24주차에 리그 내 RP 순위를 확정한다.

| 순위 | 1부 | 2부 |
|---|---|---|
| 1위 | 국가 챔피언, 판테온 컵 시드 | 자동 승격 |
| 2위 | | 자동 승격 |
| 3위 | | 승강전 진출 |
| 8위 | 승강전 진출 | |
| 9~10위 | 자동 강등 | |
| 10위 | | 파산 상태이면 리그 자격 상실 (신규 루두스로 교체) |

**승강전 (23주차)**: 1부 8위 vs 2부 3위. 대표 3판(1:1 × 3, 2선승), 미시오 규칙 고정.

## 국가 랭킹 (국가 계수)

UEFA 계수처럼 국가 대항 성적을 누적해서 국가 순위를 매긴다.

```
국가 계수 = 최근 3시즌 판테온 컵 점수의 합 ÷ 해당 시즌 출전 팀 수
판테온 컵 점수: 조별 승리 2점, 무승부(시간 종료 동점) 1점,
              8강 진출 +2, 4강 진출 +3, 결승 진출 +4, 우승 +5
```

### 국가 계수의 효과

| 순위 | 판테온 컵 출전권 | 국내 리그 배당금 배율 |
|---|---|---|
| 1~2위 | 4장 | ×1.2 |
| 3~4위 | 3장 | ×1.0 |
| 5~6위 | 1장 | ×0.85 |

- 출전권은 해당 국가 **1부 RP 순위 상위 팀**부터 배분한다.
- 플레이어가 판테온 컵에서 이기면 **조국의 계수가 오르고, 국내 모든 루두스의 배당금이 오른다**. 다른 국내 루두스가 판테온 컵에서 이기길 응원할 이유가 생긴다.

## 판테온 컵 (대륙 챔피언스 리그)

| 항목 | 내용 |
|---|---|
| 참가 | 16팀 (4+4+3+3+1+1) |
| 조별리그 | 4개 조 × 4팀, 홈·원정 2회전 (5, 7, 9, 11, 13, 15주) |
| 토너먼트 | 각 조 1·2위 → 8강(17주) → 4강(19주) → 결승(22주) |
| 경기 형식 | **대표 3판**: 선봉·중견·대장 1:1 × 3, 2선승 |
| 생사 규칙 | 조별리그·8강·4강은 미시오 고정. 결승은 **양측이 합의하면 사투** |
| 조 편성 | 같은 국가끼리 같은 조 불가. 국가 계수로 포트 분배 |
| 결승 장소 | 아우렐리온 대콜로세움 |

### 보상

| 단계 | 상금 (임시) | 기타 |
|---|---|---|
| 본선 진출 | 5,000 D | 루두스 명성 + |
| 조별 승리 1회 | 1,000 D | |
| 8강 | 4,000 D | |
| 4강 | 8,000 D | 전설 장비 추첨 |
| 준우승 | 12,000 D | |
| 우승 | 25,000 D | 전설 장비 1개, 명예의 전당, 국가 호감도 +20 |

- 판테온 컵 경기 결과는 **국내 RP에도 반영**된다 (K × 0.5).
- 같은 주에 국내 도전 경기도 할 수 있지만, 검투사는 주당 1경기 제한을 그대로 받는다. 로스터 깊이가 필요한 이유다.
- 전쟁 중인 두 나라의 루두스가 만나면 **적대전**이 된다: 관중 수입 ×2, 미시오 사망 확률 +10%p.

### 확장 후보 (MVP 이후)

- **철방패 컵**: 판테온 컵 바로 아래 순위 팀이 나가는 2부 국제 대회 (유로파 리그)
- **대륙 대표전**: 4시즌마다 국가별 올스타 대표팀 대항전. 플레이어의 검투사가 국가대표로 차출됨
