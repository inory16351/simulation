# 04. 리그와 대회

## 전체 구조

```
                    ┌─────────────────────────┐
                    │   판테온 컵 (대륙 최강전)  │  ← 국가 계수 순위로 출전권 배분
                    └────────────▲────────────┘
        ┌──────────┬──────────┬──┴───────┬──────────┬──────────┐
   아우렐리아   그롬마르    실바렌     라케다이몬    카르세아    케메르
     1부(10)    1부(10)    1부(10)   1부(10)   1부(10)    1부(10)
     2부(10)    2부(10)    2부(10)   2부(10)   2부(10)    2부(10)
```

- 국가마다 **1부 10팀 + 2부 10팀**, 대륙 전체 120개 루두스.
- 플레이어는 원하는 국가의 **2부 하위권**에서 시작한다.
- **구현**: 플레이어 나라는 1부·2부 20팀을 모두 돌린다. 나머지 다섯 나라는 **1부 10팀만** 실제 루두스로 만들어 매일 경기를 치른다 (총 70팀). 다른 나라 2부는 생략한다.
- 다른 나라 루두스끼리도 RP·배당금·유소년·이적이 똑같이 돌아간다. 이들이 판테온 컵의 상대이고, 이적 시장에서 나라를 골라 선수를 찾을 수 있다.
- 나라별 강도: 시작 국가 계수가 높은 나라일수록 1부 검투사 수준이 조금 높다.

## 랭킹 점수 (RP)

루두스 하나가 RP 하나를 가진다. **승강, 시즌 배당금, 판테온 컵 출전권**이 모두 RP 순위로 결정된다.

### 초기값과 시즌 보정

| 상황 | RP |
|---|---|
| 1부 신규·승격 팀 | 1500 |
| 2부 신규·강등 팀 | 1200 |
| 시즌 시작 시 | 리그 기준값 쪽으로 25% 회귀 (`RP = RP - (RP - 기준) × 0.25`) |

시즌 시작 회귀는 압도적인 팀이 영원히 1위를 독점하는 것을 막고, 매 시즌 경쟁을 다시 연다.

### RP 변동 (Elo 방식)

```
기대승률 E  = 1 / (1 + 10^((상대 RP - 내 RP) / 400))
RP 변동     = K × (결과 - E)          결과: 승 1, 패 0
K           = 32 × 형식 배율 × 생사 규칙 배율 × 리그 간 보정

형식 배율       : 1:1 ×1.0 / 3:3 ×1.3 / 5:5 ×1.6
생사 규칙 배율  : 훈련전 ×1.0 / 미시오 ×1.5 / 사투 ×2.0
리그 간 보정    : 2부 팀이 1부 팀을 이기면 ×1.25
```

- 강팀을 이기면 많이 오르고, 약팀을 이기면 거의 오르지 않는다. 약팀 사냥으로는 순위를 올리기 어렵다.
- **같은 상대와의 반복 경기**: 시즌 중 같은 루두스와 3번째 경기부터 RP 변동이 절반이 된다.

## 도전 시스템

정해진 대진표가 없다. 정규 기간(3~22주)에는 매주 도전을 **신청**하고 **받는다**.

### 신청 가능 범위

| 대상 | 조건 |
|---|---|
| 같은 리그 | 전부 가능 |
| 인접 리그 (1부 ↔ 2부) | RP 차이 ±200 이내 |
| 다른 국가 루두스 | **원정 친선전**만 가능 (RP 변동 없음, 상금과 국가 호감도만 변동) |

- 주당 신청 가능 횟수 = **2회** (+ 루두스 명성 단계에 따라 최대 4회).
- 출전 가능한 검투사가 없으면 신청할 수 없다.

### 도전 조건

| 항목 | 선택지 |
|---|---|
| 형식 | 1:1 / 3:3 / 5:5 |
| 생사 규칙 | 훈련전 / 미시오 / 사투 (실바렌 국내 리그는 사투 불가) |
| 지명 | 상대 검투사 1명 지명 가능. 상대는 수락하거나 대체 선수를 제시 |
| 판돈 | 0 ~ 상한(리그별, 카르세아는 2배). 승자가 모두 가져감 |
| 장소 | 받는 쪽 홈 경기장. 관중 수입은 홈 팀이 70%를 가져감 |

### 단체전 (3:3 / 5:5)

- 양쪽이 출전 순서(선봉 … 대장)를 정한다. 비워 두면 경기 날 강하고 상태 좋은 순서로 채운다.
- **승자 연속**: 첫 판의 승자가 남아 상대의 다음 사람과 싸운다. 한쪽 명단이 모두 쓰러지면 끝난다.
- 남은 체력이 다음 판으로 이어진다. 판 사이에 최대 체력의 20%만 되찾는다. 강한 선봉 하나가 셋을 쓰러뜨릴 수도 있다.
- 판마다 개인 성장·부상·죽음이 따로 적용된다 (사투 단체전은 여러 명이 죽을 수 있다).
- RP와 돈은 팀 단위로 한 번 정산한다. RP ×1.3 / ×1.6, 상금·관중 수입 ×2.2 / ×3.5.
- 명단을 다 채우지 못하면 신청할 수 없고, 경기 날 한 명도 못 내보내면 기권패 (RP -25).
- AI도 가끔 단체전을 건다 (플레이어에게 오는 도전장의 약 25%). AI끼리의 경기도 15%가 3:3이다.

### 들어온 도전에 대한 응답

| 응답 | 효과 |
|---|---|
| **수락** | 다음 주 경기 확정 |
| **역제안** | 조건 1개를 수정해서 돌려보냄. 상대 AI가 수락하거나 철회 |
| **거절** | 시즌당 무료 거절 **3회**. 이후 거절마다 RP -10, 루두스 명성 하락 |

- **하위 RP 팀의 도전을 거절**하면 페널티가 2배이고 "겁쟁이 루두스" 평판이 쌓인다. 평판이 쌓이면 관중 수입이 줄고 후원이 끊긴다.
- 사투 도전은 거절해도 페널티가 절반이다 (목숨을 걸지 않는 건 이해받는다).

### 최소 활동량

- 시즌 중 **최소 8경기**를 치러야 한다. 모자란 경기 1개당 시즌 종료 시 RP -25.
- 1위를 찍고 숨어 버티는 플레이를 막는다.

### AI 루두스 성향

| 성향 | 도전 패턴 |
|---|---|
| 공격형 | 사투·미시오를 자주 신청. 높은 RP 팀에 도전 |
| 안정형 | 훈련전 위주. 자기보다 약한 팀만 고름. 들어온 사투는 거절 |
| 원한형 | 자기 검투사를 죽인 루두스에 집요하게 도전. 사투 비율 높음 |
| 상인형 | 판돈 경기 선호. 승률이 높을 때만 신청 |
| 육성형 | 유망주를 훈련전에 내보냄. 이적 시장에서 판매에 적극적 |

국가 문화가 성향 분포에 영향을 준다 (그롬마르는 공격형, 카르세아는 상인형이 많음).

## 시즌 종료와 승강

시즌 마지막 날 리그 내 RP 순위를 확정한다.

| 순위 | 1부 | 2부 |
|---|---|---|
| 1~2위 | | 자동 승격 |
| 9~10위 | 자동 강등 | |

- 순위에 따라 시즌 배당금을 받는다 ([05 경제](05_economy.md)). 다른 나라 1부도 자기 나라 순위대로 받는다.
- 승강전(1부 8위 vs 2부 3위)은 아직 없다. 확장 후보.

## 국가 랭킹 (국가 계수)

UEFA 계수처럼 판테온 컵 성적을 쌓아 나라 순위를 매긴다.

```
시즌 점수 = 그 나라에서 출전한 루두스들의 컵 점수 평균
국가 계수 = 최근 3시즌 시즌 점수의 합
컵 점수: 대결 승리 2점, 8강·4강·결승 진출 각 1점, 우승 2점
```

- 시작 계수(3시즌치를 가정): 아우렐리아 11, 그롬마르 9.5, 라케다이몬 9, 카르세아 8, 케메르 7, 실바렌 6 (각 시즌 같은 값).
- 시즌이 끝나면 새 시즌 점수가 들어가고 가장 오래된 시즌이 빠진다.

### 국가 계수의 효과

| 계수 순위 | 판테온 컵 출전권 |
|---|---|
| 1~2위 | 4장 |
| 3~4위 | 3장 |
| 5~6위 | 1장 |

- 출전권은 조 추첨 날(서리달 15일) 그 나라 **1부 RP 순위 상위 팀**부터 준다.
- 내 루두스가 컵에서 이기면 조국의 계수가 올라 다음 시즌 출전권이 늘 수 있다.
- 계수에 따른 국내 배당금 배율은 아직 없다 (확장 후보).

## 판테온 컵 (대륙 챔피언스 리그)

| 항목 | 내용 |
|---|---|
| 참가 | 16팀 (4+4+3+3+1+1) |
| 조 추첨 | 서리달 15일. RP 순으로 네 단지에 나누고 단지마다 한 팀씩 조에 넣는다. 같은 나라는 되도록 다른 조 |
| 조별 리그 | 4개 조 × 4팀, 홈·원정 2회전 6라운드 (29, 43, 57, 71, 85, 99일) |
| 토너먼트 | 각 조 1·2위 → 8강 113일 (가1-나2, 나1-가2, 다1-라2, 라1-다2) → 4강 127일 → 결승 150일. 단판 |
| 경기 형식 | **대표 3판**: 선봉·중견·대장 1:1 × 3, 두 판을 먼저 따면 승리. 사람이 모자라면 그 판은 기권패 |
| 생사 규칙 | 미시오 고정 |
| 순위 | 승점(승 3) → 판 득실 → RP |
| RP | 리그 RP는 오가지 않는다 |
| 관중 | 상금·관중 수입 ×2, 관중 열기 +20 |
| 일정 | 컵 경기가 있는 날은 경기를 치러야 다음 날로 넘어간다. 그날 리그 경기에 나간 검투사는 쉬는 중이라 컵에 못 나간다 |

### 보상

| 단계 | 상금 |
|---|---|
| 본선 진출 | 5,000 D |
| 조별 리그 승리 1회 | 1,000 D |
| 8강 | 4,000 D |
| 4강 | 8,000 D |
| 준우승 | 12,000 D |
| 우승 | 25,000 D, 우승 기록 +1 (루두스 명성 +6) |

- 상금에는 그 나라 세금이 붙는다.
- 판마다 개인 명성·성장이 쌓인다 (미시오 기준).

### 확장 후보 (MVP 이후)

- **철방패 컵**: 판테온 컵 바로 아래 순위 팀이 나가는 2부 국제 대회 (유로파 리그)
- **대륙 대표전**: 4시즌마다 국가별 올스타 대표팀 대항전. 플레이어의 검투사가 국가대표로 차출됨
