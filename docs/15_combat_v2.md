# 15. 전투 v2 — 수 싸움

[03 전투](03_combat.md)의 판정 위에 **방향·동작을 서로 읽는 수 싸움**을 얹는다. 1:1 리그, 단체전, 던전, 야수전이 모두 같은 엔진을 쓴다.
출발점은 `전투 로직 설계.md`의 두 줄이다.

> 무기와 전투 형태마다 상성이 있어 가위바위보처럼 물고 물리고, 예측력·판단력·팀워크·천재성 같은 능력치가 공격 로직에 이어져서, 운과 능력치 배분에 따라 더 강한 적도 쓰러뜨릴 수 있어야 한다.

## 0. 결정 사항 (2026-11-02 사용자 확인)

| 항목 | 결정 |
|---|---|
| 적용 범위 | 1:1, 단체전, 던전, 야수전 전부. 엔진 하나 |
| 상성 단위 | **공격 동작 × 방어 동작** 가위바위보. 무기군은 어떤 동작을 잘 쓰는지로 간접 상성 |

| 예측 근거 | 검투사마다 버릇이 있다. 경기 안에서 읽고, 정찰·지난 경기 기록도 쓴다 |
| 새 능력치 | 예측력, 기만, 천재성, 적응력, 팀워크, 타이밍, 마무리 본능, 위압감 (8개, 전부 공개) |

| 플레이어 개입 | 경기 전 교범 + 경기 중 외침 |
| 몬스터·야수 | 종마다 뚜렷한 고정 패턴과 약점 |
| 연출 | 중계 문장 + 탑뷰 화면의 이펙트·액션 |

## 1. 새 능력치: 전투 감각 (8)

기존 신체·기술·정신 옆에 네 번째 분류 **전투 감각**을 만든다. 1~20, 상대 것은 스카우트 범위로 보인다.

| 능력치 | id | 하는 일 |
|---|---|---|
| **예측력** | `read` | 상대가 칠 방향·동작을 맞히는 정확도. 정찰 기록을 얼마나 잘 쓰는지 |
| **기만** | `feint` | 페인트로 상대 예측을 속인다. 상대 예측력을 깎는 쪽 |
| **천재성** | `genius` | 변칙 수를 연다 (장기 성장). 경기 중 버릇에 없는 즉흥 수 |
| **적응력** | `adapt` | 경기 중 상대 버릇을 배우는 속도. 후반으로 갈수록 강해진다 |
| **팀워크** | `team` | 위험한 동료 알아채기, 구하러 가기, 협공 타이밍 |
| **타이밍** | `timing` | 선공 잡기, 방어 성공 뒤 반격, 빈틈(헛친 내려치기·스태미나 바닥) 파고들기 |
| **마무리 본능** | `kill` | 무너진 상대·빈사 상대를 끝내는 힘. 낮으면 놓치고 회복할 틈을 준다 |
| **위압감** | `aura` | 상대 기세·침착을 깎고 예측을 흔든다. 투지·침착이 낮은 상대에게 강하다 |

### 기존 능력치의 역할 조정

| 능력치 | v2에서 추가되는 역할 |
|---|---|
| 판단력 | 교범·외침을 따르는 정도 (지금 그대로) + 상대 예측을 역이용해 수를 고르는 품질 |
| 반응 | 방어 동작 성공 보조. 방향을 틀렸을 때 늦게라도 반응할 확률 |
| 공격성 | 높을수록 버릇이 단순해진다 (읽히기 쉽다). 대신 공격 합을 더 자주 잡는다 |
| 침착 | 위압감·위기(HP 낮음)에 따른 예측 흔들림 저항 |
| 일관성 (숨김) | 경기마다 예측·기만에 붙는 컨디션 노이즈 |

## 2. 한 합

경기는 **합**의 연속이다. 한 합에 한쪽이 공격자, 다른 쪽이 방어자다.

### 2.1 공격권

```
선공 점수 = 타이밍 × 2 + 반응 + 민첩 / 2 - 무기 속도 × 2 - 방어구 민첩 페널티 + 직전 합 결과 보정 + 난수(0~10)
```

- 높은 쪽이 공격자. 직전 합에서 방어가 크게 이겼으면 방어자가 공격권을 가져간다 (반격).
- 공격성이 높으면 선공 점수에 보너스, 대신 방어 동작 선택 품질이 떨어진다.
- 거리가 안 맞으면 공격 대신 이동 합이 된다 (거리 3단계는 03 그대로).

### 2.2 동시에 숨겨서 고르기

| 쪽 | 고르는 것 |
|---|---|
| 공격자 | 방향 (상·중·하) × 공격 동작 (베기·찌르기·내려치기) + 페인트 여부 |
| 방어자 | 막을 방향 (상·중·하) × 방어 동작 (막기·흘리기·피하기) |

### 2.3 동작 상성

공격 동작마다 강한 방어 하나, 약한 방어 하나, 중립 하나.

|  | 막기 | 흘리기 | 피하기 |
|---|---|---|---|
| **베기** | 불리 (방패에 걸림) | 중립 | **유리** (넓은 궤적이 피하는 몸을 잡음) |
| **찌르기** | **유리** (방패 틈을 찌름) | 불리 (빗겨냄) | 중립 |
| **내려치기** | 중립 | **유리** (너무 무거워 흘릴 수 없음) | 불리 (크게 헛쳐 빈틈) |

막기 > 베기 > 피하기 > 내려치기 > 흘리기 > 찌르기 > 막기 로 한 바퀴 돈다.

### 2.4 결과

| 방향 | 동작 상성 | 결과 |
|---|---|---|
| 틀림 | 아무거나 | **클린 히트.** 방어 판정 없이 명중 판정만. 공격 유리 동작이면 치명타 +15% |
| 맞춤 | 방어 유리 | **완전 방어.** 피해 0, 공격자 자세 흐트러짐, 방어자에게 반격 판정 (타이밍) |
| 맞춤 | 중립 | 기존 판정 (명중·막기·회피 능력치). 03 공식 그대로 |
| 맞춤 | 공격 유리 | **방어 무너짐.** 피해 ×0.6을 받고 방어자는 다음 합 `무너짐` (선공 불가, 방어 선택 -1단계) |

- 클린 히트·방어 무너짐 피해에는 상성 배율 ×1.5를 곱한다 ("강하게" 결정).
- 방향이 틀려도 반응이 높으면 `늦은 반응` 확률 `반응 × 1.5%`로 "맞춤 + 중립" 결과로 내려간다.
- 능력치는 여전히 숫자를 정한다. 수 싸움은 **어떤 판정표를 쓰는지**를 정한다.

### 2.5 무기·장비가 동작에 주는 영향

| 무기군 | 잘 쓰는 동작 (보정 +) | 못 쓰는 동작 (보정 -) |
|---|---|---|
| 한손검 | 베기, 찌르기 | — |
| 곡검 | 베기 (방패 우회: 막기 상대 불리 완화) | 내려치기 |
| 대검 | 베기, 내려치기 | 찌르기 |
| 도끼 | 내려치기 (막기 상대도 방패 파손) | 찌르기 |
| 둔기 | 내려치기 | 찌르기 |
| 창·삼지창 | 찌르기 | 내려치기 |
| 단검 | 찌르기 | 내려치기 |
| 맨손 | 찌르기(주먹) + 제압 동작 | 베기 |

- 방패: 막기 보정 (03의 방패 보정). 방패가 없으면 막기 대신 무기 막기 (보정 낮음).
- 중장갑: 피하기 -, 막기 +. 경갑: 피하기 +.
- 스킬은 동작에 붙는다 (강타=내려치기, 관통 찌르기=찌르기, 연속 베기=베기 2회). 스킬은 동작 상성을 그대로 받는다.

## 3. 버릇과 예측

### 3.1 버릇

- 검투사마다 **공격 버릇**(방향 3 × 동작 3 = 9칸 분포)과 **방어 버릇**(9칸 분포)이 있다.
- 처음 버릇은 스타일·무기·종족 성향 + 난수로 만든다. 공격성이 높으면 분포가 뾰족하다 (한두 칸에 몰림).
- 교범의 "노리는 곳"·"동작 비중"이 버릇에 얹힌다. 교범으로 버릇을 틀면 그만큼 숙련도 손해 (13 전술).
- 버릇은 시간이 지나며 바뀐다: 천재성이 새 칸을 키우고, 규율 높은 검투사는 훈련(버릇 고치기)으로 분포를 고르게 만든다.

### 3.2 공격자의 선택

```
기본: 공격 버릇에서 뽑는다
판단력 판정 성공 시: 상대가 막을 것 같은 칸을 피해 상성이 유리한 칸으로 비튼다
천재성 즉흥: 확률 천재성 × 0.5%로 버릇에 거의 없는 칸을 고른다 (상대 예측 모델 밖)
페인트: 기만 판정. 성공하면 상대 예측은 '보여 준 칸' 기준으로 계산된다
```

### 3.3 방어자의 예측

방어자는 공격자의 버릇을 **추정**해서 막을 칸을 고른다.

```
추정 분포 = 사전 기록(정찰·지난 경기, 예측력과 스카우트 정확도만큼 믿음) + 이번 경기 관측(합마다 적응력만큼 갱신)
학습률      = 0.10 + 적응력 × 0.015 (합당)
읽기 흔들림 = 기본 - 예측력 × k + 상대 기만 × k + 상대 위압감 영향 - 침착 보정 + 일관성 노이즈
→ 흔들림이 작을수록 추정 분포에서 가장 유력한 칸을 정확히 고르고, 크면 무작위에 가까워진다
```

- 방어 동작은 "그 칸의 공격 동작에 유리한 방어"를 고르되, 판단력이 낮으면 자기 방어 버릇으로 쏠린다.
- 결과: 버릇이 뾰족한 강자는 예측력·적응력 높은 약자에게 **경기 후반에 읽혀서** 진다. 이게 이변의 주 경로다.

### 3.4 천재성: 변칙 수 (장기 성장)

| 천재성 | 열리는 수 | 효과 |
|---|---|---|
| 10 | 꺾어 치기 | 방향을 바꾸는 페인트. 기만 판정에 천재성 보너스 |
| 14 | 역동작 | 같은 동작으로 다른 동작 상성을 낸다 (상성표 한 칸 돌림) |
| 18 | 사선 | 네 번째 방향. 방어가 맞출 수 없지만 명중 -15% |

- 경기를 치를수록 천재성 판정으로 버릇에 새 칸이 생긴다 (레퍼토리 확장). 성장 화면에 "새 수를 익혔다"로 알린다.

### 3.5 나머지 감각 능력치

| 능력치 | 공식 (초안) |
|---|---|
| 타이밍 | 반격 성공 = 30% + 타이밍 × 2.5%. 상대 헛친 내려치기·스태미나 0 → 다음 합 선공 확정 확률 타이밍 × 4% |
| 마무리 본능 | 상대 HP 30% 이하 또는 `무너짐`일 때 명중 + 마무리 × 1%, 피해 + 마무리 × 1.5%. 낮으면(≤6) 그 상태 상대에게 숨 돌릴 합을 준다 |
| 위압감 | 경기 시작·치명타·완전 방어 때 상대 기세 -(위압감 - 상대 침착)/2, 상대 읽기 흔들림 +. 투지 10 미만 상대는 2배 |

## 4. 1:1 경기 흐름

- 최대 40합 (기존 30턴을 대체). 이동 합, 스킬 합, 숨 고르기 합도 합으로 센다.
- 스태미나: 동작마다 소모 (찌르기 < 베기 < 내려치기). 페인트는 추가 소모.
- 기세·항복·시간 종료·사망 판정은 03 그대로.

### 4.1 외침 (경기 중 개입)

FM의 터치라인 지시처럼, 경기 중 **작전 타임** 때 외침을 고른다.

- 작전 타임: 10합·20합·30합, 그리고 내 검투사 HP가 50%·25% 아래로 처음 떨어질 때. 한 경기 최대 3번 외친다.
- 외침이 먹히는 정도 = 판단력 + 교범 숙련도. 공격성 높고 흥분(기세 낮음)하면 무시할 수 있다.

| 외침 | 효과 |
|---|---|
| "하단을 노려라" (방향 지정) | 공격 버릇을 그 방향으로 크게 비튼다 |
| "버릇을 깨라" | 몇 합 동안 공격 분포를 평평하게. 스태미나 추가 소모 |
| "놈은 OO를 자주 친다" | 그 칸 예측에 보너스 (정찰 기록과 겹치면 더 큼) |
| "버텨라" / "몰아쳐라" | 자세 변경 (철벽 / 맹공) |
| "끝내라" | 마무리 본능 판정 보너스, 방어 약화 |

- AI 루두스도 같은 외침을 자동으로 쓴다 (교관 판단력 기준).
- 구현: 경기 시뮬레이션을 작전 타임마다 멈췄다 이어 가는 단계형으로 만든다. "결과만" 모드에서는 자동 외침.

## 5. 단체전·던전: 위치 기반

### 5.1 마당

- 탑뷰 마당을 칸으로 나눈다 (초안 16×10). 말마다 좌표, 이동 속도(민첩·방어구), 사거리(근 1칸 / 중 2~3칸 / 원 4칸 이상).
- 틱마다: 각자 목표를 정하고 이동 → 붙은 쌍끼리 한 합씩 (2장 규칙 그대로).
- 진형(`FORMATIONS`)은 시작 위치와 역할 성향이 된다.

### 5.2 팀워크 행동

말마다 매 틱 **위험한 동료**를 찾는다: HP 35% 이하, `무너짐`, 둘 이상에게 둘러싸임, 쓰러지기 직전.
알아채는 거리와 확률은 팀워크, 지금 목표를 버리고 갈지는 판단력으로 정한다.

| 행동 | 조건 | 효과 |
|---|---|---|
| **끼어들기** | 동료를 몰아치는 적에게 닿을 수 있음 | 그 적에게 붙어 목표 전환 판정 (그 적의 판단력 대 내 위압감·팀워크) |
| **대신 막기** | 동료 옆 칸 | 동료에게 오는 합을 내가 대신 방어 (내 막기·예측력으로) |
| **끌고 후퇴** | 쓰러지기 직전 동료 옆 칸 | 둘 다 느리게 뒤로. 그동안 동료는 마무리 일격을 받지 않는다. 사투에서도 그 합의 사망을 막는다 |
| **협공** | 둘이 같은 적과 붙음 | 방어자는 한 방향밖에 못 막는다. 두 공격자의 팀워크 평균으로 '동시' 판정: 성공하면 둘째 공격은 방어 틀림 처리, 실패하면 차례로 공격하고 둘째에 명중 +10%만 |

### 5.3 원거리·주술·주장

- 원거리·주술은 사거리 안 아무나 노린다. 전열이 막고 있으면 명중 -.
- 주장 규칙(리더십, 쓰러지면 기세 -20)은 13 전술 그대로.

---

## 6. 몬스터·야수: 고정 패턴

- 종마다 **고정 버릇**(뾰족한 분포)과 **약점 동작**, **특수 패턴**이 있다.
- 예: 사막 사자 = 하단 돌진(찌르기 취급) 60%, 피하기에 약하다. 동굴곰 = 상단 내려치기 70%, 흘리기 불가, 피하기에 무너진다.
- 예측력·적응력 높은 검투사는 몇 합 만에 패턴을 읽는다. 한 번 싸운 종은 **도감 기록**이 남아 다음 원정부터 사전 기록으로 쓴다.
- 보스는 HP 구간마다 패턴이 바뀐다 (적응력이 다시 중요해짐).

---

## 7. 경기 간 기록 (정찰)

- 루두스는 본 경기(자기 경기, 같은 리그 공개 경기)의 상대 버릇 관측치를 쌓는다.
- 스카우트 정확도만큼 노이즈를 섞어 **상대 버릇 리포트**로 보여 준다 (예: "상단 내려치기를 자주 씀, 하단 방어가 약함").
- 교범에 "상대 버릇 대응"을 켜면 사전 기록을 예측에 쓴다. 예측력이 높을수록 더 믿는다.
- 반대로 내 검투사의 버릇도 상대에게 쌓인다 → 같은 상대와 여러 번 붙으면 천재성·버릇 고치기가 중요해진다.

---

## 8. 승패 철학

- **CA는 판정에 들어가지 않는다.** CA는 표시와 성장 상한(PA)에만 쓴다.
- 이변은 숨겨서 고르기, 버릇 읽기, 상성, 외침에서 나온다. 순수 난수(명중·치명타 굴림)는 조연이다.
- 확인 방법: 테스트에서 같은 두 검투사를 1,000번 붙이고, 교범·외침·버릇만 바꿨을 때 승률이 크게 움직이는지 본다. 능력치를 몰빵한 검투사가 상성 나쁜 상대에게 지는 경우가 실제로 나와야 한다.

## 11.1 구현 상태 (2026-11-02)

| 단계 | 상태 | 비고 |
|---|---|---|
| 1. 능력치 8개 | **완료** | `types.ts` `SENSE`, 검투사 화면 '전투 감각' 칸, 훈련 '실전 감각', 실전 성장에 예측력·적응력·타이밍·마무리. 예전 저장은 `fillSenseAttrs`로 채움 |
| 2. 1:1 합 엔진 | **완료** | `combat/exchange.ts` + `sim.ts` `runExchange`. 중계 문장 (`commentary.ts` `exchange`) |
| 3. 밸런스 실험 | 1차 완료 | `npx tsx tools/duel-lab.ts [경기 수]` |
| 4~7 | 아직 | 외침, 정찰 버릇 리포트, 위치 기반 팀 엔진, 몬스터 패턴, 탑뷰 이펙트 |

설계와 달라진 점 (튜닝 결과):
- 피해 배율: 클린 히트 ×1.25 (동작까지 유리하면 ×1.5, 치명타 +15%), 방어 무너짐 ×0.9. 설계의 "클린 히트 늘 ×1.5"는 경기가 너무 짧아져서 낮췄다.
- 공격권은 별도 합이 아니라 기존 라운드 순서 공식에 타이밍을 넣었다 (`타이밍 + 반응/2 + 민첩/2 - 무기 속도×2 + 난수 8`, 무너지면 -6, 상대가 무너졌거나 지쳤으면 +타이밍×0.6).
- 타이밍은 수 싸움 명중에도 `(타이밍-10)×1.2%`, 완전 방어 뒤 반격 확률 `20% + 타이밍×4%`.
- 천재성은 즉흥 수 외에 버릇을 고르게 만든다 (레퍼토리가 넓다). 꺾어 치기(10)·사선(18)은 들어갔고 역동작(14)은 아직.
- 적응력은 관측 가중치 `0.4 + 적응력×0.12`에 더해, 합이 쌓일수록 예측이 날카로워진다 (`(적응력-8)×0.01×min(라운드,20)`).
- 공격자가 "많이 보여 준 방향을 피하는" 판단은 판단력·기만 대 상대 예측력 대결로 확률이 정해진다. 그냥 판단력만으로 하면 읽기가 무력화됐다.
- 곡검은 막기에 완전 방어당하지 않는다 (중립으로 내려감).

1차 측정 (`duel-lab`, 훈련전):
- 합 결과: 클린 59%, 완전 방어 15%, 무너짐 10%, 중립 9%, 늦은 반응 7%. 평균 14라운드, 시간 종료 1% (예전 19%).
- 같은 검투사에서 감각 하나만 18 대 5: 예측력 84%, 적응력 68%, 기만 66%, 마무리 61%, 위압감 58%, 천재성 53%, 타이밍 53%.
- 약자(목표 8, 감각 17) 대 강자(목표 12, 감각 6): 약자 평균 60%. 스타일 상성에 따라 7%~100%.
- 시즌 시뮬 (`npm run sim`): CA 20 이상 차이 이변율 10% (예전 9%). 사투 사망률 94% (시간 종료가 줄어서 예전 77%보다 높다).
- 스타일 승률 차가 크다: 파쇄자 ~70%, 판크라티아스트 ~31%, 트라키아·레티아리우스 ~41%. 다음 튜닝 대상.
