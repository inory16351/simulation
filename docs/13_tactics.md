# 13. 전술 — 전투 교범

FM은 **팀 전술**이 중심이다. 이 게임은 **검투사 한 명 한 명의 전술**이 중심이다.
검투사마다 자기만의 **전투 교범**(싸우는 방식)을 갖고, 라니스타는 교범을 짜고 다듬고 상대에 맞춰 고친다. 단체전 전술은 그 위에 얹는 얇은 층이다.

## 1. 전투 교범 (개인 전술)

검투사마다 교범이 하나 있고, 경기 전에 상대에 맞춰 수정할 수 있다.

| 항목 | 선택지 | 효과 |
|---|---|---|
| **자세** | 맹공 / 균형 / 철벽 / 견제 / 쇼맨십 / 속전속결 | 행동 선택의 기본 성향 |
| **거리** | 스타일 기본 / 파고들기 / 중거리 유지 / 멀리서 견제 | 어느 거리에서 싸우려 하는가 |
| **노리는 곳** | 고르게 / 머리 / 몸통 / 다리 / 무기 든 팔 | 명중률과 부가 효과의 맞교환 |
| **기술 순서** | 액티브 스킬 4칸의 우선순위 | 같은 상황이면 앞 순서부터 쓴다 |
| **조건 명령** | 최대 3줄 (아래) | 경기 중 상황이 바뀌면 자동으로 행동을 바꾼다 |
| **항복** | 허용 / 끝까지 싸움 | 끝까지 싸우면 살아날 길이 줄어든다 |

### 자세

| 자세 | 효과 |
|---|---|
| 맹공 | 공격 빈도↑, 공격 스킬 우선. 막기·회피 스킬은 거의 안 씀 |
| 균형 | 기본값 |
| 철벽 | 방어 스킬 우선, 받는 피해↓, 공격 빈도↓. 상대 스태미나를 말린다 |
| 견제 | 거리를 유지하며 치고 빠진다. 사거리 긴 무기·그물에 유리 |
| 쇼맨십 | 관중 열광을 최대로 쌓는다. 미시오에서 목숨을 건지는 보험 |
| 속전속결 | 비싼 스킬을 초반에 몰아 쓴다. 스태미나가 빨리 바닥난다 |

### 노리는 곳

| 부위 | 명중 | 효과 |
|---|---|---|
| 고르게 | 기본 | 없음 |
| 머리 | -15% | 치명타 +10%, 기절 확률 |
| 몸통 | +10% | 효과 없음. 안정적인 누적 피해 |
| 다리 | -5% | 명중 시 30% 확률로 2턴간 민첩 저하 (거리 조절·회피 약화) |
| 무기 든 팔 | -10% | 명중 시 30% 확률로 2턴간 상대 피해 -25% |

### 조건 명령 (최대 3줄)

`만약 [조건]이면 [명령]` 형태로 적는다. 위에서부터 먼저 맞는 한 줄만 실행된다.

| 조건 | 명령 |
|---|---|
| 내 HP가 N% 이하 | 자세를 바꾼다 (예: 철벽으로) |
| 상대 HP가 N% 이하 | 특정 스킬을 최우선으로 쓴다 |
| 내 스태미나가 N% 이하 | 숨을 고른다 |
| 상대가 속박·넘어짐 상태 | 특정 스킬을 최우선으로 쓴다 / 거리를 좁힌다 |
| N라운드 이후 | 자세를 바꾼다 |

예시 — 그물투사 교범:
```
자세: 견제 / 거리: 중거리 유지 / 노리는 곳: 다리
기술 순서: 그물 투척 → 관통 찌르기 → 거리 벌리기
1. 상대가 속박 상태면 → 관통 찌르기 최우선
2. 내 HP 35% 이하면 → 자세를 쇼맨십으로 (미시오 대비)
3. 내 스태미나 20% 이하면 → 숨 고르기
```

### 교범 숙련도

- 교범을 바꾸면 **숙련도**가 0부터 다시 쌓인다. 숙련도가 낮으면 조건 명령을 늦게 알아채고, 자세 효과도 약하다.
- 숙련도는 연무장 훈련(교범 수련)과 실전으로 오른다.
- **판단력**이 높은 검투사는 숙련도가 낮아도 교범을 잘 따르고, 낮은 검투사는 흥분하면 교범을 무시한다 (공격성이 높으면 맹공 쪽으로 쏠림).
- 상대마다 교범을 바꾸는 것은 강하지만, 숙련도 손해가 있다. **"자기 교범을 완성한 검투사"** 가 이 게임의 강자다.

## 2. 단체전 전술 (3:3, 5:5)

검투사 각자의 교범은 그대로 쓰고, 그 위에 팀 단위 지시를 한 겹 얹는다.

### 3:3 전용

| 항목 | 선택지 |
|---|---|
| 진형 | **삼각** (전열 2·후열 1) / **일렬** (전원 전열) / **창끝** (전열 1·후열 2) |
| 표적 | 가장 약한 적 / 가장 위협적인 적 / 상대 주장 / 각자 판단 |
| 역할 (1인 1개) | 선봉(먼저 붙음) · 수호(아군을 노리는 적을 막음) · 사냥꾼(약해진 적 마무리) |
| 연계 | **협공**: 같은 적을 두 명이 노리면 명중 +10% / **엄호**: 수호 역할이 옆 아군 피격 일부를 대신 막음 |

### 5:5 전용

| 항목 | 선택지 |
|---|---|
| 진형 | **방패벽** (전열 3·후열 2, 방어↑) / **쐐기** (중앙 돌파, 공격↑) / **포위** (양 날개 전진, 측면 공격↑) / **산개** (원거리·주술 유리) |
| 표적 | 3:3과 같음 + **지정 대상** |
| 역할 | 선봉 · 수호 · 사냥꾼 · **지휘**(리더십으로 아군 기세 유지) · **원호**(투척·주술로 후방 지원) |
| 주장 | 리더십이 가장 높은 검투사 자동 지정 또는 직접 지정. 주장이 쓰러지면 아군 기세 -20 |
| 퇴각 신호 | 아군 N명이 쓰러지면 남은 인원 항복 허용 (미시오에서 전멸 방지) |

진형과 역할은 **각자의 교범과 충돌할 수 있다.** 예: 견제 교범의 그물투사를 선봉에 세우면 효율이 떨어진다. 팀 전술보다 개인 교범이 우선하고, 충돌하면 그 검투사의 판단력으로 어느 쪽을 따를지 정한다.

## 3. 대표 3판 (판테온 컵·승강전)

1:1을 세 번 하므로 팀 전술 없이 **누구를 어느 순서에 세우는지**가 전술이다.

- 선봉·중견·대장 순서를 경기 전에 비공개로 제출한다.
- 상대의 지난 출전 순서와 교범 경향이 정찰 보고서에 나온다 (스카우트 판독 능력에 따라 정확도가 다름).
- 판마다 교범을 바꿀 수 있다.
